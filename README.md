Solara Bay — an original open-world crime game built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC. Explore a sun-soaked coastal city on foot and by car, steal cars, outrun the Solara Bay police, and run five story missions for the fixer Marisol Vega. No Rockstar Games names, characters, art or assets — the city, story, vehicles and music are all original.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — every file the game loads lives under `game/`.

WASD to move and drive, E to enter or steal a car, mouse to aim, click to shoot, Shift to sprint, Esc to pause, M to mute. Your progress saves automatically after each mission.
